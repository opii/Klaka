# Sadržaj portala

- `articles.json` — članci koje je jednom napisao lokalni LLM (`../scripts/write-articles.mjs`), sa
  početnim komentarima. Bez njega portal ima samo četiri ručno pisana članka iz `src/content.ts`.
- `img/<id>.jpg` — dokumentarne fotografije uz članke (640×360 JPEG, služe se na `/img/<id>.jpg`).
